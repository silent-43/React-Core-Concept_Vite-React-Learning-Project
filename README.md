# 🚀 Vite + React Learning Project

This is a practice project built using **React + Vite**.  
The goal of this project is to learn and implement core and intermediate React concepts through hands-on coding.

---

## 📌 Overview

In this project, multiple components are created to display data fetched from APIs.  
It also demonstrates modern React features like **Suspense**, **props**, and **event handling**.

---

## ⚛️ Features

- ✅ Component-based structure
- ✅ API data fetching (Fetch API)
- ✅ Async/Await & Promises
- ✅ React Suspense for loading state
- ✅ Props passing between components
- ✅ Multiple reusable components
- ✅ Event handling (different methods)
- ✅ Basic CSS styling

---

## 🧠 Concepts Covered

- React Components
- Props (data passing)
- useState Hook
- Fetch API
- Async/Await
- Promises
- React Suspense
- Event Handling


---

## 🌐 API Sources

This project uses free public APIs:

- https://jsonplaceholder.typicode.com/posts
- https://jsonplaceholder.typicode.com/albums
- https://jsonplaceholder.typicode.com/comments

---


## 🎮 What This Project Does

- Fetches data (Users, Friends, Albums, Comments) from APIs
- Displays data using separate React components
- Shows loading state using React Suspense
- Demonstrates different types of button click handling

---

## 🎯 Event Handling Examples

- Normal function
- Arrow function
- Inline function
- Passing parameters in event handler

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
